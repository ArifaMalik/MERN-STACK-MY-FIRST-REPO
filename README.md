🛒 Commerce Store Project

  

📌 Project Overview

This project is a modern E-commerce (Commerce Store) web application where users can browse products, add to cart, and place orders.


---

✨ Features

🛍️ Product Listing

🔍 Search & Filter

🛒 Add to Cart

💳 Checkout System

🔐 User Authentication

📦 Order Management
